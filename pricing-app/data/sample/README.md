# Sample data (SYNTHETIC)

Every number in these CSVs is invented by `generate.mjs`. They exist only so the app can be run and
demonstrated before the real seed files are available. Do not use them for any business decision.

The three SKUs from DATA_SPEC section 3 (`9.EC22`, `70.JP9`, `SXLSK`) are included with the same
implied unit figures the spec quotes, so the UOM reconciliation screen can be tried against them.

Load with `npm run seed:sample`. Real data: see `../seed/README.md`.

# SK Keong

Two internal tools for SK Keong Trading Sdn. Bhd.:

- **`index.html` / `app.py`** – the ROI calculator (static page published to GitHub Pages; Streamlit version).
- **`pricing-app/`** – the pricing and field-intelligence PWA (UOM reconciliation, tier prices with
  history, offline price lookup, competitor-price capture, visit prep, price intelligence, CSV import).
  See `pricing-app/README.md`.
